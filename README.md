# fardinalam13.github.io

Personal portfolio of **Fardin Alam Alif** — Full-Stack Software Engineer (.NET / Angular).

Live: https://fardinalam13.github.io

## Stack

Plain HTML, CSS and JavaScript. No build step.

- Fonts: [Inter](https://fonts.google.com/specimen/Inter)
- Icons: Font Awesome 6, Devicon
- Hosting: GitHub Pages

## Structure

```
index.html          single-page site
css/style.css       theme tokens (dark/light), layout, components
js/main.js          theme toggle, mobile nav, scroll reveal, counters, typing effect
assets/
  favicon.svg
  Fardin_Alam_CV.pdf   ← add your latest CV here (linked by the "Download CV" button)
  img/                 headshot + compressed project screenshots (WebP)
```

## Run locally

Open `index.html` in a browser, or use the VS Code "Live Server" extension.

## Deploy

Push to the `main` branch of the `fardinalam13.github.io` repository. GitHub Pages serves the root.
